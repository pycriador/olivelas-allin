# Sprint 4.2 — Centro de Operacoes

**Status:** Concluida  
**Commit:** `8b8fc6c`  
**Objetivo:** Unificar a operacao da campanha em um unico hub multi-aba com metricas, grade, pedidos, CRM e midia.

---

## O que foi implementado

Centro em `/campanhas/{id}` com abas via `?tab=`:

| Tab                       | Conteudo                                               |
| ------------------------- | ------------------------------------------------------ |
| Visao Geral               | Progresso (% vendido/reservado), metricas, financeiro  |
| Grade Visual              | Edicao inline de status (clique / menu de contexto)    |
| Numeros                   | DataTable com filtros e busca (numero, nome, telefone) |
| Pedidos                   | Resumo financeiro, export, impressao                   |
| Clientes / CRM            | Cards + historico                                      |
| Midia                     | Galeria tipada                                         |
| Artes                     | Gerador de canvas                                      |
| Configuracoes / Contato   | WhatsApp do organizador, settings                      |
| Reservas (pos)            | Lista e limpeza de reservas                            |
| Sorteio (Sprint 9)        | Draw e vencedores                                      |
| Participantes (Sprint 11) | Agregacao por cliente                                  |

### NumberDrawer

Sheet lateral com:

- status do numero
- cliente e pedido vinculados
- historico
- acoes: liberar, trocar, marcar pago

### Realtime operacional

- `useRealtimeCampaign` na grade
- `useRealtimeOrders` na aba de pedidos

### Navegacao

- URLs diretas por aba (bookmarkable)
- Sub-navegacao da campanha no menu lateral
- Reformas mobile (tabs scroll, touch targets)
