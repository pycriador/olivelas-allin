# Sprint 4.1 — Vendas Manuais e CRM

**Status:** Concluida  
**Commits:** `57db5d4`, consolidado em `8b8fc6c`  
**Objetivo:** Transformar reserva em pedido comercial e criar CRM de clientes + fluxos manual e WhatsApp.

---

## O que foi implementado

### CRM de clientes

- CRUD: nome, telefone, email, cidade, observacoes
- Soft delete
- Pagina `/clientes`

### Pedidos (Orders) como centro comercial

Toda venda gera:

```
Order → order_items → atualiza campaign_numbers → alimenta dashboard
```

Fontes (`order_source`):

- `ONLINE`
- `WHATSAPP`
- `MANUAL`

Status (`order_status`):

```
OPEN | WAITING_CONTACT | WAITING_PAYMENT | PAID | CANCELLED | EXPIRED | REFUNDED
```

### Venda manual

- Seletor de campanha, cliente e numeros
- Metodo de pagamento, desconto, status inicial
- Dialog `ManualSaleDialog`

### Importacao de numeros

- Lista TXT/CSV → pedido automatico (`import_sold_numbers`)

### Fluxo WhatsApp

1. Reserva publica
2. Cria Order `WAITING_CONTACT` (`create_whatsapp_order`)
3. Abre `wa.me` com template para o organizador
4. Admin marca como pago / avanca status

### Comprovantes e timeline

- Upload de imagem/PDF em `order_receipts`
- Historico por pedido (`ActivityTimeline`)
