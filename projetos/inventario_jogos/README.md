# Game Catalog Manager

Eu quero uma página que eu envie uma string com o nome do jogo, preço, URL, que faça um parser dessas informações e mostre em formato de lista para download. Quero uma opção de deletar o item, adicionar manualmente e editar, pois que eu quero colocar uma descrição do produto antes. Na estrutura, eu quero uma coluna com o nome do jogo, a descrição que eu vou colocar depois, o preço e uma coluna com o texto original.
