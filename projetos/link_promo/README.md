# PromoLink Maker

Eu quero uma aplicação que eu coloque uma URL do Mercado Livre ou da Shopee, que colete a informação "Nome do produto", "Antigo Preço", "Preço Novo" , "Quantas vezes"

Com essas informações, quero utilizar um template que vai substituir as tags pelas informações coletadas, por exemplo: https://www.mercadolivre.com.br/metroid-prime-4-beyond-nintendo-switch-2-edition/p/MLB62059689?pdp_filters=seller_id%3A92087939#polycard_client=search-desktop&search_layout=grid&position=1&type=product&tracking_id=a86bee51-c4e2-458b-a065-8803652ca765&wid=MLB6047629310&sid=search

Vai pegar o nome Metroid Prime 4: Beyond Nintendo Switch 2 Edition, o valor que é R$383 em 12x R$37,47

Quero um local para colar a URL, escolher o template e depois aparecerá o link curto (usar os principais encurtadores grátis) com a mensagem em texto

Quero que os dados fiquem armazenados no site, mas quero ter a opção de editar as URL's enviadas ou deletar. Quero que salve a URL original, a nova URL, todas as informações encontradas na página.

Quero a opção de editar, criar ou editar novas mensagens personalizadas.

Quero que colete corretamente o valor do produto, está no código fonte do site
