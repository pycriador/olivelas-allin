# Visão Computacional

Módulo de análise e classificação de imagens utilizando modelos de visão computacional dos provedores de IA configurados.

## Funcionalidades

- Classificação de imagens por categoria
- Detecção de objetos e rostos
- Extração de descrições automáticas
- Reconhecimento de logotipos e marcas
- Moderação de conteúdo visual
- Integração com OCR para documentos mistos
- Armazenamento de resultados de análise
