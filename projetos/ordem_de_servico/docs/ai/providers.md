# Gerenciamento de Provedores de IA

Gerencia as credenciais, modelos e configurações de conectividade com provedores de inteligência artificial como OpenAI, Anthropic, Google Gemini e Azure OpenAI Service.

## Funcionalidades

- Cadastro de múltiplos provedores simultâneos
- Configuração de chaves de API com criptografia
- Seleção de modelos disponíveis por provedor
- Definição de provedor padrão para fallback
- Teste de conectividade integrado
- Monitoramento de limites de taxa (rate limits)
- Rotação automática entre provedores
