# Validação por QR Code

Sistema de validação documental via QR code que permite autenticar a integridade e autenticidade de documentos digitalmente.

## Funcionalidades

- Geração de QR code com hash criptográfico
- Validação em portal público
- Verificação de integridade do documento
- Confirmação de assinaturas vinculadas
- Dados de autenticação no QR code
- Expiração configurável da validação
- Relatório de validações realizadas
- API pública de consulta
