# Controle de Versão de Documentos

Sistema de versionamento que mantém histórico completo de alterações em documentos com comparação e restauração.

## Funcionalidades

- Versionamento automático a cada alteração
- Comparação visual entre versões
- Restauração de versões anteriores
- Nomeação e descrição de versões
- Bloqueio de versão para evitar alterações
- Histórico com metadados do autor
- Diferenciação de conteúdo textual
