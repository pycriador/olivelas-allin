# Cadastros (Master Data)

Módulo central de cadastros do ServiceForge, responsável por armazenar e gerenciar todas as entidades fundamentais do sistema. Serve como base de dados para os demais módulos, garantindo consistência e integridade das informações.

Através deste módulo é possível manter registros atualizados de clientes, equipamentos, técnicos, fornecedores, peças, serviços e demais tabelas de apoio utilizadas em toda a plataforma.

## Funcionalidades

- Cadastro completo de clientes (pessoas físicas e jurídicas)
- Catálogo de dispositivos e equipamentos com dados técnicos
- Registro de técnicos com dados profissionais e habilitações
- Tabelas de fabricantes, marcas, modelos e categorias
- Catálogo de defeitos, serviços e peças
- Cadastro de fornecedores, formas e condições de pagamento
- Gerenciamento de garantias e unidades de medida
