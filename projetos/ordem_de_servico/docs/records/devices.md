# Dispositivos

Cataloga os equipamentos e dispositivos dos clientes que são objeto de ordens de serviço. Permite rastrear todo o histórico de manutenções por equipamento, incluindo dados técnicos e de garantia.

## Funcionalidades

- Cadastro de equipamentos por cliente
- Dados técnicos: número de série, modelo, fabricante
- Histórico completo de serviços realizados
- Controle de garantia por equipamento
- Associação de peças e acessórios
- Status operacional e localização
