# Unidades de Medida

Catálogo de unidades de medida utilizadas para dimensionar peças, serviços e produtos no sistema. Garante a padronização das grandezas em todos os módulos.

## Funcionalidades

- Cadastro de unidades (kg, m, h, un, etc.)
- Sigla e descrição por unidade
- Conversão entre unidades compatíveis
- Associação a produtos e peças
- Suporte a unidades fracionárias
