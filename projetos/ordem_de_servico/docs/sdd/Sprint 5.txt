# ServiceForge — Sprint 5
## Communication Platform

Continuar o desenvolvimento do projeto ServiceForge.

NÃO alterar nenhuma arquitetura criada nas sprints anteriores.

NÃO remover funcionalidades existentes.

Toda implementação deve respeitar:

- Core Platform
- Metadata Platform
- Document Platform
- Providers
- Services
- Repository Pattern
- Audit Service

O objetivo desta Sprint é criar o módulo de Comunicação.

------------------------------------------------------------------

# Objetivo

Criar uma plataforma centralizada de comunicação.

Todos os módulos futuros deverão utilizar este módulo para enviar mensagens.

Garantia

# Objetivo da Sprint

Ao finalizar esta Sprint o ServiceForge deverá possuir uma plataforma completa de comunicação preparada para:

- enviar mensagens;
- anexar documentos;
- criar templates;
- controlar histórico;
- gerenciar canais;
- executar regras;
- preparar futuras integrações externas.

IMPORTANTE

Ainda NÃO implementar:

- Core Event Bus
- Workflow Engine completo
- WhatsApp API real
- Email real
- Ordem de Serviço
- IA
