# ServiceForge — Sprint 4
## Document Platform

Continuar o desenvolvimento do projeto ServiceForge.

NÃO alterar nenhuma arquitetura criada anteriormente.

NÃO remover funcionalidades já implementadas.

Toda implementação deverá respeitar exatamente a arquitetura modular existente.

Nesta Sprint será desenvolvido o módulo de Documentos.

Este módulo será responsável por toda geração, armazenamento, impressão, exportação, versionamento e gerenciamento de documentos da plataforma.

IMPORTANTE

Ainda NÃO implementar geração real de PDF.

Ainda NÃO integrar bibliotecas externas.

Toda geração poderá utilizar HTML como representação visual.

A arquitetura deverá estar preparada para PDF futuramente.

------------------------------------------------------------------

OBJETIVO

Criar um módulo chamado:

Documents

que será utilizado por toda a plataforma.

Nenhum módulo deverá gerar documentos diretamente.

Todos utilizarão este módulo.
