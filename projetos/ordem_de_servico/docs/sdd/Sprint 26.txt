# ServiceForge — Sprint 26
## Service Order Module — Customer Management (Clientes, Endereços, Contatos e Histórico)

Continuar o desenvolvimento do projeto ServiceForge.

Toda arquitetura existente deverá ser preservada.

NÃO remover funcionalidades implementadas.

NÃO alterar a arquitetura da plataforma.

Toda implementação deverá respeitar integralmente:

• Foundation Platform

• Core Platform

• Metadata Platform

• Master Data Platform

• Data Platform

• Integration Platform

• Administration Platform

• Reporting & BI Platform

• Automation Platform

• Document Platform

• Communication Platform

• AI Platform

• Public Portal

• Workflow Engine

• Core Event Bus

Todo o módulo deverá consumir os serviços já existentes.

Nunca duplicar lógica.

Nunca criar CRUDs isolados.

Todos os formulários deverão utilizar Metadata Platform.

Toda auditoria deverá utilizar Audit Center.

Toda comunicação deverá utilizar Communication Platform.

Todos os documentos deverão utilizar Document Platform.

------------------------------------------------------------------

OBJETIVO

Implementar o módulo completo de Gestão de Clientes.

Este módulo será responsável por todo o cadastro de clientes da plataforma.

Os clientes poderão ser compartilhados entre empresas através do Administrador Global.

Toda Ordem de Serviço utilizará obrigatoriamente este cadastro.
