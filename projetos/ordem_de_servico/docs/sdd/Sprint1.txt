# ServiceForge — Sprint 1
## Foundation Platform (Arquitetura Base)

Vamos iniciar um novo projeto chamado **ServiceForge**.

O objetivo é construir uma plataforma SaaS moderna para gestão de Assistências Técnicas, utilizando arquitetura modular e preparada para crescimento.

IMPORTANTE:

Neste momento NÃO utilizar Lovable Cloud.

NÃO utilizar Supabase do Lovable.

Toda persistência deverá funcionar localmente através de uma camada de abstração.

O objetivo desta sprint é construir apenas a fundação da plataforma.

------------------------------------------------------------------

Utilizar:

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- TanStack Router

- React Hook Form

- Zustand

Não utilizar Next.js.

------------------------------------------------------------------

## Persistência

NÃO utilizar LocalStorage diretamente dentro dos componentes.

Criar uma camada de persistência.

Exemplo:

StorageProvider

com interface semelhante a:

create()

update()

delete()

find()

findAll()

count()

clear()

transaction()

No MVP criar apenas um provider chamado:

LocalStorageProvider

Toda a aplicação deve consumir apenas a interface.

Nunca acessar LocalStorage diretamente.

No futuro existirão:

SupabaseProvider

PostgreSQLProvider

MariaDBProvider

SQLiteProvider

Todos implementando exatamente a mesma interface.

------------------------------------------------------------------

## Database Manager

Criar um módulo chamado:

Database Manager

Responsável por:

- listar conexões
- conexão ativa
- criar conexão
- editar conexão
- excluir conexão
- testar conexão

Neste MVP todas as conexões serão mockadas.

Tipos suportados:

• Local Storage
• Supabase
• PostgreSQL
• MariaDB
• SQLite

Ainda não conectar em nenhum banco.

Apenas preparar toda a arquitetura.

------------------------------------------------------------------
