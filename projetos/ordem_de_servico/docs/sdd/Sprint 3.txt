# ServiceForge — Sprint 3
## Metadata Platform

Continuar o desenvolvimento do projeto ServiceForge.

NÃO alterar a arquitetura criada nas sprints anteriores.

NÃO substituir componentes existentes.

Todo novo código deverá seguir exatamente os padrões arquiteturais já implementados.

O objetivo desta Sprint é desenvolver o Metadata Platform, que será utilizado por todos os módulos do sistema.

IMPORTANTE

O Metadata Platform NÃO é um construtor de banco de dados.

Ele é responsável pela configuração dinâmica da plataforma.

Toda persistência continua utilizando apenas dados locais.

Nenhum backend.

Nenhuma integração externa.

------------------------------------------------------------------

## Objetivo

Criar um módulo responsável por definir:

• Formulários

• Campos

• Listagens

• Dashboards

• Templates

• Configurações

Todos os demais módulos deverão consumir essas definições.

# Objetivo desta Sprint

Ao finalizar esta Sprint o sistema deverá possuir um Metadata Platform completo, capaz de gerenciar entidades, campos, formulários, listagens, dashboards e templates, servindo como base para os módulos de Documentos, Comunicação e Ordem de Serviço.

IMPORTANTE

Ainda NÃO implementar geração de documentos.

Ainda NÃO implementar workflows.

Ainda NÃO implementar Event Bus.

O foco desta Sprint é apenas a configuração dinâmica da plataforma.
