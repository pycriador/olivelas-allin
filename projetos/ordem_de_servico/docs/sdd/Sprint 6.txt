# ServiceForge — Sprint 6
## Core Event Bus + Workflow Engine

Continuar o desenvolvimento do projeto ServiceForge.

NÃO alterar a arquitetura existente.

NÃO remover funcionalidades já implementadas.

Todos os módulos existentes deverão passar a utilizar o Core Event Bus para comunicação interna.

Esta Sprint é responsável por criar a infraestrutura de eventos da plataforma.

IMPORTANTE

Ainda NÃO implementar Ordem de Serviço.

Ainda NÃO implementar IA.

O objetivo é criar o motor responsável por integrar todos os módulos da plataforma.

------------------------------------------------------------------

OBJETIVO

Criar dois módulos:

Core Event Bus

Workflow Engine

Eles serão responsáveis pela orquestração de toda a plataforma.

Nenhum módulo deverá chamar outro diretamente.

Toda comunicação ocorrerá através de eventos.

# Objetivo da Sprint

Ao finalizar esta Sprint o ServiceForge deverá possuir um barramento de eventos completamente funcional e um Workflow Engine capaz de responder a eventos publicados pelos módulos existentes.

A plataforma deverá estar preparada para que todos os futuros módulos utilizem eventos internos como principal mecanismo de integração.
