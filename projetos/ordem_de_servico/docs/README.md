## 🏛️ Estrutura da Documentação / Documentation Structure

A documentação do ServiceForge v1.0.0-RC1 adota o framework de engenharia bilíngue com foco em contexto progressivo e governança de IA:

- **Visão Geral do Projeto** (`project-overview.md`): Propósito, escopo, não-objetivos e módulos.
- **Contexto de IA** (`ai-context.md`): Ponto de entrada hierárquico (Níveis 0 a 6) para agentes autônomos.
- **Arquitetura** (`architecture/architecture.md`): C4 model, topologia de frontend TanStack Start, backend Supabase/PostgreSQL.
- **Contratos** (`contracts/contracts.md`): Esquemas de dados, tipagens TypeScript e APIs REST.
- **Operações** (`operations/operations.md`): Build, desenvolvimento, deploy no GitHub Pages e Cloudflare.
- **Segurança** (`security/security.md`): Row Level Security (RLS), views `security_invoker`, RBAC e auditoria.
