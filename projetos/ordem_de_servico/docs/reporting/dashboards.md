# Construtor de Dashboards

Ferramenta visual para criação de dashboards personalizados com arrastar e soltar de widgets, gráficos e indicadores.

## Funcionalidades

- Editor visual com layout flexível
- Arrastar e soltar de widgets
- Grid responsivo e temas
- Múltiplas abas por dashboard
- Filtros globais e por widget
- Compartilhamento com permissões
- Duplicação e exportação de dashboard
