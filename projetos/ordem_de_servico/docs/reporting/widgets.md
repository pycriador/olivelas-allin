# Biblioteca de Widgets

Catálogo de componentes visuais reutilizáveis para construção de dashboards, incluindo tabelas, cartões de KPI, gráficos e indicadores.

## Funcionalidades

- Widgets pré-construídos por categoria
- Cartão de KPI com sparkline
- Tabela dinâmica com paginação
- Indicador de meta com gauge
- Navegador hierárquico (tree)
- Lista de alertas e notificações
- Widgets customizados via SDK
