# Gerenciamento de Datasets

Administração das fontes de dados utilizadas em relatórios e dashboards, com suporte a consultas SQL, APIs e arquivos.

## Funcionalidades

- Conexão com bancos de dados relacionais
- Consultas SQL com validação
- Datasets a partir de APIs externas
- Upload de arquivos CSV, JSON e XLSX
- Agendamento de atualização de dados
- Transformação e limpeza inline
- Cache e performance de consultas
