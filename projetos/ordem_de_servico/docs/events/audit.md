# Auditoria de Eventos

Trilha de auditoria de todas as operações no barramento de eventos, incluindo mudanças em subscribers e workflows.

## Funcionalidades

- Registro de alterações em subscribers e workflows
- Log de ativação/desativação
- Identificação de usuário e IP
- Carimbo de data/hora preciso
- Consulta com filtros avançados
- Exportação para SIEM
- Retenção configurável
