# Fila de Mensagens

Sistema de fila para processamento assíncrono de envio de mensagens com priorização, retry e controle de throughput por canal.

## Funcionalidades

- Enfileiramento com prioridades
- Controle de throughput por canal
- Retry automático com backoff
- Dead letter queue para falhas
- Cancelamento de mensagens na fila
- Visualização de status em tempo real
- Métricas de throughput e latência
