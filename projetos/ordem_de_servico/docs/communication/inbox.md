# Caixa de Entrada

Caixa de entrada unificada que centraliza todas as mensagens recebidas de diferentes canais em uma única interface de visualização e resposta.

## Funcionalidades

- Bandeja única para todos os canais
- Visualização de conversas encadeadas
- Resposta direta pelo canal de origem
- Atribuição de conversas a usuários
- Marcação e categorização
- Busca textual em mensagens
- Anexos e mídia inline
