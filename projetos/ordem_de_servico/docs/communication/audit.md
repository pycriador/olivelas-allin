# Auditoria de Comunicação

Trilha de auditoria de todas as operações realizadas na plataforma de comunicação, incluindo envios, configurações e alterações de regras.

## Funcionalidades

- Registro de todas as operações de envio
- Log de alterações em templates e regras
- Identificação de usuário e IP
- Carimbo de data/hora preciso
- Consulta com filtros avançados
- Exportação para SIEM
- Retenção configurável
