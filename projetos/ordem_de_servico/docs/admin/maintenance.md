# Admin — Modo de Manutenção

Ativa e gerencia o modo de manutenção da plataforma, que restringe o acesso de usuários durante atualizações, migrações ou correções críticas.

## Funcionalidades

- Ativação imediata ou programada do modo de manutenção
- Página personalizada de aviso para usuários finais
- Lista de IPs autorizados a acessar durante a manutenção
- Modo de manutenção seletivo por módulo ou empresa
- Agendamento com contagem regressiva e notificação
- Fila de requisições para processamento pós-manutenção
- Log de ações realizadas durante o período de manutenção
