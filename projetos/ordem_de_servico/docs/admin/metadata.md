# Admin — Metadados

Gerencia os metadados do sistema, incluindo esquemas de dados, dicionários, campos customizados e classificações. Permite estender a modelagem de dados sem alterações no código fonte.

## Funcionalidades

- Definição de campos customizados por entidade e módulo
- Dicionário de dados com descrição de todos os campos do sistema
- Classificações e tags para organização de conteúdo
- Versionamento de esquemas e migração assistida
- Validação de tipos, formatos e valores permitidos
- Importação e exportação de definições de metadados
- Integração com fontes de dados para sincronização de esquemas
