# Admin — Banco de Dados

Gerencia as conexões com bancos de dados utilizados pela plataforma. Permite configurar, testar e monitorar bancos relacionais e não relacionais de forma centralizada.

## Funcionalidades

- Cadastro de múltiplas conexões com banco de dados
- Suporte a PostgreSQL, MySQL, SQL Server, MongoDB e Oracle
- Teste de conectividade e validação de credenciais
- Monitoramento de pool de conexões e queries lentas
- Configuração de réplicas de leitura e failover
- Visualização de métricas de desempenho por conexão
