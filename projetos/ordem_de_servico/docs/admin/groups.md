# Admin — Grupos

Organiza os usuários em grupos lógicos para facilitar a atribuição de permissões e funções em lote. Grupos podem representar departamentos, equipes ou níveis organizacionais.

## Funcionalidades

- Criação e gerenciamento de grupos personalizados
- Associação de usuários a múltiplos grupos simultaneamente
- Atribuição de funções (roles) diretamente aos grupos
- Herança de permissões entre grupos hierárquicos
- Auditoria de alterações na composição dos grupos
- Integração com diretórios LDAP/AD
