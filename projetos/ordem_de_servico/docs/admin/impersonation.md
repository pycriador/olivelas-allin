# Admin — Impulsionamento (Impersonation)

Permite que administradores acessem a plataforma como se fossem outro usuário, facilitando o suporte técnico e a resolução de problemas sem compartilhamento de credenciais.

## Funcionalidades

- Início de sessão como outro usuário com autorização explícita
- Registro completo em log de todas as ações durante a sessão
- Indicação visual clara de que a sessão está impulsionada
- Restrição por função — apenas administradores master podem impulsionar
- Expiração automática da sessão impulsionada
- Histórico de auditoria dedicado para sessões impulsionadas
