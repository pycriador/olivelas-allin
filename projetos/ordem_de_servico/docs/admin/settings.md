# Admin — Configurações Globais

Centraliza as configurações gerais da plataforma, incluindo preferências de sistema, regionalização, formatos padrão e parâmetros operacionais que afetam todos os módulos.

## Funcionalidades

- Configuração de idioma e fuso horário padrão
- Formato de data, hora, moeda e números
- Configurações de e-mail (remetente, templates, limites)
- Parâmetros de paginação e exibição padrão
- Configurações de privacidade e retenção de dados
- Personalização da página de login e e-mails transacionais
- Definição de feriados e dias úteis para cálculos
