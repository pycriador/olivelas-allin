# Admin — Saúde do Sistema

Exibe o status operacional de todos os componentes da plataforma, incluindo bancos de dados, serviços, filas e dependências externas. Permite diagnóstico rápido de falhas e degradação.

## Funcionalidades

- Painel de status com indicadores verde/amarelo/vermelho
- Verificação de conectividade com bancos de dados e serviços
- Latência de resposta de APIs internas e externas
- Status de filas de jobs e workers
- Uso de disco, memória e CPU por serviço
- Histórico de disponibilidade (uptime) dos componentes
- Webhook para notificação de falhas em tempo real
