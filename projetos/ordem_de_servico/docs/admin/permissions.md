# Admin — Permissões

Gerencia as permissões individuais do sistema, permitindo controle refinado sobre cada ação disponível na plataforma. Permissões são os blocos fundamentais do RBAC.

## Funcionalidades

- Catálogo completo de permissões disponíveis no sistema
- Criação de permissões personalizadas para módulos específicos
- Associação direta de permissões a funções (roles)
- Visualização de permissões por módulo e contexto
- Busca e filtro por nome, módulo ou recurso
- Validação de consistência e permissões órfãs
