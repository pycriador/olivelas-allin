# Admin — Temas

Gerencia a aparência visual da plataforma através de temas customizáveis. Permite criar, editar e aplicar temas que definem cores, tipografia, logotipos e layout do sistema.

## Funcionalidades

- Criação de temas personalizados com editor visual
- Paleta de cores configurável (primária, secundária, fundo, texto)
- Upload de logotipos, favicons e imagens de fundo
- Definição de tipografia e espaçamentos
- Aplicação de temas por empresa ou grupo de usuários
- Temas claro e escuro com alternância automática
- Exportação e importação de temas completos
