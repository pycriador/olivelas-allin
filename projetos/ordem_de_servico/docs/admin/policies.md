# Admin — Políticas de Segurança

Configura as políticas de segurança que governam autenticação, senhas, sessões e bloqueios na plataforma. Garante a conformidade com boas práticas e requisitos regulatórios.

## Funcionalidades

- Configuração de complexidade e expiração de senhas
- Definição de bloqueio por tentativas inválidas
- Políticas de sessão (tempo de idle, expiração máxima)
- Regras de autenticação multifator (MFA) por grupo ou função
- Lista de IPs permitidos e bloqueados
- Integração com SSO e provedores OAuth
- Políticas de senha para diferentes níveis de acesso
