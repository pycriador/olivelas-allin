# Admin — Fontes de Dados

Gerencia as fontes de dados que alimentam os módulos da plataforma, incluindo bancos, APIs externas, arquivos e streams. Centraliza a configuração de acesso a dados heterogêneos.

## Funcionalidades

- Cadastro de fontes de dados relacionais, NoSQL e APIs REST
- Configuração de schedulers para sincronização periódica
- Mapeamento de esquemas e transformação de dados
- Validação de conectividade e qualidade dos dados
- Monitoramento de latência e volume de dados trafegados
- Histórico de sincronizações e erros
