# Entidades

**Módulo:** Admin > Metadata  
**Caminho:** `/admin/metadata/entities`  
**Versão:** 1.0.0-RC1

## Descrição

Gerenciamento de entidades do sistema. Permite definir e configurar as entidades que compõem o modelo de dados da plataforma.

## Funcionalidades

- Cadastro de novas entidades
- Edição de entidades existentes
- Exclusão de entidades
- Definição de propriedades básicas (nome, descrição, ícone, cor)
- Controle de ativação/inativação

## Campos

| Campo | Tipo | Descrição |
|-------|------|-----------|
| Nome | Texto | Nome único da entidade |
| Descrição | Texto | Descrição da entidade |
| Ícone | Ícone | Ícone representativo |
| Cor | Cor | Cor de identificação |
| Status | Status | Ativo / Inativo |

## Ações

- **Novo**: Abre formulário para cadastrar nova entidade
- **Editar**: Altera os dados de uma entidade existente
- **Excluir**: Remove a entidade (confirmação necessária)
