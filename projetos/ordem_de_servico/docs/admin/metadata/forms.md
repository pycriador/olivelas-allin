# Formulários

**Módulo:** Admin > Metadata  
**Caminho:** `/admin/metadata/forms`  
**Versão:** 1.0.0-RC1

## Descrição

Designer de formulários dinâmicos. Permite criar e configurar formulários baseados nas entidades e campos definidos.

## Funcionalidades

- Designer visual de formulários
- Arrastar e soltar campos
- Configuração de layout e grupos
- Definição de regras de exibição
- Visualização em tempo real

## Campos

| Campo | Tipo | Descrição |
|-------|------|-----------|
| Nome | Texto | Nome do formulário |
| Entidade | Referência | Entidade associada |
| Layout | JSON | Configuração de layout do formulário |
| Status | Status | Rascunho / Publicado |

## Ações

- **Novo Formulário**: Cria um novo formulário
- **Designer**: Abre o editor visual
- **Publicar**: Publica o formulário para uso
- **Duplicar**: Cria uma cópia do formulário
