# Admin — Funções (Roles)

Define as funções disponíveis no sistema, que agregam conjuntos de permissões para controle de acesso baseado em papéis (RBAC). Funções podem ser atribuídas a usuários ou grupos.

## Funcionalidades

- Criação de funções personalizadas com permissões granulares
- Associação de funções a usuários e grupos
- Clonagem de funções existentes para agilizar a configuração
- Visualização hierárquica de permissões por função
- Funções padrão do sistema (Admin, Gerente, Operador, Visualizador)
- Validação de conflitos e sobreposição de permissões
