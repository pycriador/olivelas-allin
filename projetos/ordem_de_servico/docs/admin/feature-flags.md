# Admin — Feature Flags

Gerencia as feature flags da plataforma, permitindo ativar ou desativar funcionalidades de forma granular sem necessidade de deploy. Ideal para testes A/B, liberação progressiva e rollback rápido.

## Funcionalidades

- Ativação/desativação de funcionalidades por ambiente
- Segmentação por empresa, grupo de usuários ou porcentagem
- Programação de ativação em data/hora específica
- Sobrescrita por usuário para testes direcionados
- Histórico de alterações e auditoria de toggles
- Cache inteligente com propagação em tempo real
