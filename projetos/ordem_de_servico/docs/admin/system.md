# Admin — Informações do Sistema

Exibe informações detalhadas sobre a plataforma, incluindo versão do software, dependências, ambiente de execução, configurações de servidor e componentes instalados.

## Funcionalidades

- Versão atual do ServiceForge e data de build
- Lista de módulos instalados e suas versões
- Informações do ambiente (SO, Node.js, banco de dados)
- Dependências do sistema e bibliotecas instaladas
- Configurações de servidor web e aplicação
- Uptime e estatísticas de desempenho do servidor
- Diagnóstico rápido de configuração e compatibilidade
