# Conexões de Integração

Gerenciamento das conexões ativas com sistemas externos, incluindo credenciais, autenticação e status de conectividade.

## Funcionalidades

- Cadastro de conexões por conector
- Autenticação OAuth, API Key e Basic Auth
- Criptografia de credenciais em repouso
- Teste de conectividade
- Monitoramento de status (online/offline)
- Reconexão automática
- Expiração e renovação de tokens
