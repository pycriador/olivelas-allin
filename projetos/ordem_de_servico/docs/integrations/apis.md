# Gerenciamento de APIs

Portal de gerenciamento de APIs internas e externas com controle de acesso, documentação e monitoramento.

## Funcionalidades

- Catálogo de APIs disponíveis
- Chaves de API com escopos e permissões
- Rate limiting por chave e rota
- Documentação interativa (Swagger/OpenAPI)
- Logs de requisições
- Versão de API e depreciação
- Análise de uso por endpoint
