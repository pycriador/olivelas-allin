# Engine de Sincronização

Motor de sincronização bidirecional de dados entre o ServiceForge e sistemas externos com mapeamento de campos e agendamento.

## Funcionalidades

- Sincronização bidirecional e unidirecional
- Mapeamento visual de campos
- Agendamento recorrente de sincronia
- Sincronização incremental e completa
- Resolução de conflitos configurável
- Log detalhado de cada sync
- Reexecução de sincronizações falhas
