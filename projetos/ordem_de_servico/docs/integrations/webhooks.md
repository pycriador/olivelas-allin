# Gerenciamento de Webhooks

Sistema completo de webhooks para receber notificações de sistemas externos e disparar eventos para integrações configuradas.

## Funcionalidades

- Webhooks de entrada com validação de payload
- Webhooks de saída para notificar sistemas
- Segurança com assinatura HMAC e tokens
- Filtros por tipo de evento
- Retry automático em falhas de entrega
- Log de todas as requisições recebidas
- URL secreta e rate limiting
