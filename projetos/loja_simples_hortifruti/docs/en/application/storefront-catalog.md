## Storefront & Dynamic Catalog

The primary storefront interface ([index.html](../../../index.html)) provides the end-user shopping experience.

## Key Features

1. **Unified Search Bar**: Positioned at the top of the catalog section (`#catalog-search-input`), performing instant debounced queries across product titles, descriptions, categories, and tags.
2. **Category Filter Pills**: Quick filter buttons for "All", "Fruits", "Greens & Leaves", "Vegetables", "Organics", and "Herbs & Spices".
3. **Smart Sorting**: Sort by Lowest Price, Highest Price, Alphabetical (A-Z), or Featured items.
4. **Card Information Badges**:
   - `Made to Order`
   - `Last Unit`
   - `Low Stock`
   - `Out of Stock`
   - `Featured` / `Organic`
5. **Smart Pagination**: Smooth page navigation controls with item count indicators.

See [product-modals.md](product-modals.md) for details on product detail interactions.
