## Privacidade e Tratamento de Dados

A aplicação foi projetada com o princípio de **Privacy by Design**, garantindo respeito total aos dados do consumidor.

## Princípios de Privacidade

1. **Sem Rastreamento Invasivo**: A aplicação não emprega cookies de terceiros para rastreamento comportamental de anúncios.
2. **Dados de Pedido Transitórios**: As informações de entrega (nome, endereço, telefone) são mantidas temporariamente na memória/localStorage do dispositivo do usuário apenas durante a sessão de compra.
3. **Transmissão Direta**: Os dados do pedido são enviados exclusivamente para o WhatsApp do lojista, sem intermediação de servidores de terceiros.
4. **Conformidade LGPD**: Os dados pessoais são processados estritamente para a finalidade de execução da entrega solicitada pelo cliente.
