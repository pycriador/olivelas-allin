# Contribuindo para o Hortifruti Natural

Agradecemos o seu interesse em contribuir para o projeto **Hortifruti Natural**!

## Diretrizes de Desenvolvimento

1. **Módulos ES6 Vanilla**: Mantenha o código frontend modular, limpo e livre de dependências pesadas de runtime.
2. **Tokens de Design**: Utilize as variáveis CSS declaradas em `assets/css/variables.css`.
3. **Esquema de Produtos**: Ao adicionar produtos ou recursos, siga o esquema em `docs/pt-BR/contracts/produtos-json-schema.md`.
4. **Documentação**: Atualize a documentação em `docs/pt-BR/` e `docs/en/` ao modificar componentes ou contratos.
5. **Validação**: Execute `python scripts/docs_lint.py validate` antes de commitar.
