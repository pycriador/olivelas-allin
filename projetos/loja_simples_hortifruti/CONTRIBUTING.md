# Contributing to Hortifruti Natural

Thank you for your interest in contributing to **Hortifruti Natural**!

## Development Guidelines

1. **Vanilla ES6 Modules**: Keep frontend code clean, modular, and dependency-free.
2. **Design Tokens**: Use CSS custom properties defined in `assets/css/variables.css`.
3. **Product Schema**: When adding products or features, adhere to `docs/en/contracts/produtos-json-schema.md`.
4. **Documentation**: Update documentation in both `docs/en/` and `docs/pt-BR/` when changing components or contracts.
5. **Validation**: Run `python scripts/docs_lint.py validate` before committing.
